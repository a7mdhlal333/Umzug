# Umzug Frontend

## Voraussetzungen

Node.js und npm muessen installiert sein.

## Starten

```powershell
npm install
npm start
```

Die Anwendung ist danach unter `http://localhost:4200` erreichbar. Das Backend muss parallel unter `http://localhost:8080` laufen.

Der Angular-Dev-Server leitet `/api` automatisch an das Spring-Boot-Backend weiter.
